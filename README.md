# Notification Service

## Overview

The **notification-service** is responsible for delivering notifications across the Marketplace platform.

It processes notification events generated by other services and delivers them through the appropriate communication channel while respecting user preferences and delivery policies.

The service supports asynchronous, reliable, scalable, and multi-channel notification delivery.

---

# Responsibilities

The notification-service is responsible for:

- Push notifications
- Email notifications
- SMS notifications
- In-app notifications
- Notification templates
- Notification preferences
- Delivery tracking
- Retry mechanisms
- Notification history
- Event-driven notification processing
- Multi-language notification support

---

# What This Service Does NOT Handle

This service does **not**:

- Authenticate users
- Manage bookings
- Process payments
- Handle escrow logic
- Manage realtime connections
- Store business logic
- Manage user profiles
- Process chat or voice calls
